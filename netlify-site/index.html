Student Academic Dependency Analyzer

Paste marks for 5 to 8 academic components. The analyzer finds which components repeat each other, keeps the independent ones, and rebuilds them as perpendicular performance directions.

Summary

    1. Feature matrix A

    Rows are students, columns are components. Each column is a vector in R.

    2. Rank and elimination

    Gauss-Jordan elimination reduces A. Pivot columns (teal) are independent. Others (orange) are dependent.
